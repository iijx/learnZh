## 1. 产品概述

### 1.1 一句话定位

给不识字或识字很少的老人用的**系统识字课**——「老年大学识字班」的线上版：每天 5 个字，100 天认遍 500 个最常用的字，学完能读菜单、看站牌、认药盒。

### 1.2 背景与问题

- 中国仍有数千万低识字水平老人（扫盲标准：认识 1500 字为脱盲），他们在日常生活中处处受阻：看不懂药品说明书、菜单、站牌、短信，去医院银行无法填表签字。
- 这类老人**有强烈学习动机**（生活刚需），但线下扫盲班资源少、离家远、怕丢面子。
- 他们普遍会用智能手机基础操作和微信，但**不识字决定了传统 App 界面（文字导航）对他们形同虚设**——这是本产品最大的设计挑战，也是护城河。

### 1.3 产品目标

- 让零基础老人**完全自主**完成每天的学习，无需子女全程陪同。
- MVP 学完入门级 500 个高频字（覆盖日常文本约 75%），达到「出门能认路牌、吃药能认药名」的水平。
- 北极星指标：**每周学习 ≥3 天的活跃学员数**。

## 2. 目标用户

### 2.1 核心用户：学员（老人）

| 维度 | 描述 |
|---|---|
| 年龄 | 55–80 岁 |
| 识字水平 | 接近零基础（认识名字和极少数常见字） |
| 设备能力 | 会智能机基础操作：解锁、打开微信、发语音、点按钮 |
| 身体特点 | 视力减退（花眼/白内障）、听力下降、记忆力弱、手指灵敏度低 |
| 学习动机 | 生活刚需：看药品说明书、认菜单站牌、读短信、签字 |
| 心理特点 | 怕出错丢面子、需要大量鼓励、容易半途放弃 |

### 2.2 次级用户：传播者（子女）

| 维度 | 描述 |
|---|---|
| 角色 | 发现产品 → 帮父母点开并收藏 → 偶尔查看学习进度 |
| 动机 | 孝心经济：希望父母生活自理能力提升 |
| 触点 | 家庭群、朋友圈、小程序分享卡片 |

### 2.3 典型使用场景

- 早上起床后，打开微信 → 点开小程序 → 复习昨天的字 → 学 5 个新字 → 收到鼓励 → 放下手机
- 在菜市场看到价签，认出刚学的「元」「斤」，产生成就感
- 收到子女短信，能认出大部分字，第一次没让邻居帮忙念

## 3. 课程体系设计

### 3.1 教学法：高频字优先 + 场景应用

- **主线**：按国家语委字频数据排序教学，先学最常用的字（的、一、是、了、我、人……），确保每个阶段学的字都能立即组合成生活句子。
- **场景应用**：每学满 25 字解锁一节「生活场景课」，把学过的字放进真实场景（菜单、站牌、药盒、短信、银行叫号屏）里认一遍，强化「学了能用」的获得感。
- **记忆锚点**：字谜顺口溜、古诗、小故事三件套贯穿课程，解决孤立认字记不住、没动力的问题（详见 3.8）。

### 3.2 字库与分级

| 级别 | 字数 | 达成水平 | 周期（5 字/天） |
|---|---|---|---|
| 入门级 | 500 高频字 | 覆盖日常文本约 75%，应付基本生活场景 | 100 天 |
| 进阶级 | +500 字 | 覆盖约 90%，流畅读报 | 再 100 天 |
| 达标级 | +500 字 | 共 1500 字，达到国家脱盲标准 | 再 100 天 |

> MVP 范围 = 入门级 500 字 + 20 节场景课 + 写名字专项。

### 3.3 单字教学闭环（每个字，半自动播放）

```
大字展示 + AI插画  →  TTS读字音×2  →  大白话讲解(字形故事+字义+记字诀)
     ↓
笔顺动画×2  →  手指描红（默认不考核）  →  组词2–3个(配图配音)
     ↓
生活例句1句(大字+朗读)  →  练习：听音选字×2 + 描红×1  →  语音提示进入下一字
```

要点：
- 全程自动播放，只在描红、听音选字环节停下等操作。
- 讲解文案用**大白话口语**（「药，就是生病吃的那个东西」），禁用书面语。
- 每字时长控制在 2–3 分钟，5 字一课约 15 分钟。

### 3.4 每日学习流程

```
打开小程序 → 语音问候+今日任务播报
   → 先复习：遗忘曲线到期字批量听音选字（每题2–3秒，总复习≤5分钟）
   → 学5个新字（半自动课堂）
   → 结束：语音表扬+进度播报（「你已经认识138个字了！」）
```

### 3.5 练习题型

| 题型 | 形式 | 说明 |
|---|---|---|
| 听音选字 | 语音读字音，4 张大字卡片选正确一张 | 核心题型，不需要读题面 |
| 描红跟写 | 手指跟着笔顺轨迹描 | 默认不考核；设置开启后按轨迹吻合度**宽松评分**（粗略判定即可） |

> 原则：**凡需要读题面的题型一律不用**（用户不识字）。组词造句属于教学环节，不作为考题。

### 3.6 复习机制

- 每个字在学完后的**第 1、2、4、7、15 天**自动进入复习队列。
- 复习题型 = 批量听音选字（轻量、快速），答错的字 24 小时后再次出现。
- 复习排期在服务端计算，换设备不丢失。

### 3.7 场景应用课（每 25 字一节）

场景：菜市场价签、公交站牌、药品说明书、菜单、手机短信、银行叫号屏、超市货架、医院科室牌。

形式：真实感场景大图 + 大字高亮 + 语音引导，让老人在场景里「找出你认识的『药』字在哪里」——找到 3 个即过关，给予大幅表扬。

### 3.8 记忆三件套

孤立认字没有记忆锚点，也难以提供情感动力。三件套分别解决「记什么」「为什么学」「学了能干嘛」：

**① 字谜/顺口溜（记字诀）——每个字的教学标配**

- 每个字配一条「记字诀」：民间现成字谜优先（「一口咬掉牛尾巴——告」「门里有个人——闪」「二小二小头上长草——蒜」），缺失的用大模型批量生成 + 人工审核。
- 融入单字教学闭环的讲解环节（见 3.3）。
- 老人这代人在字谜文化里长大，学会后「拿去考人」自带传播。

**② 古诗里程碑课——每学满 50 字解锁一首，共 10 首**

- 选材原则：五言绝句为主、用字尽量落在已学字、允许 ≤20% 未学字（课内大字+语音顺带讲解，不考核，登记进队列后正式学）。
- 建议序列（可调）：50 字《一去二三里》→ 100 字《咏鹅》→ 150 字《画》→ 200 字《悯农》→ 250 字《春晓》→ 300 字《静夜思》→ 350 字《登鹳雀楼》→ 400 字《游子吟》→ 450 字《相思》→ 500 字《梅花》。
- 课堂形式：大字逐句认读 + 跟读 + 「背给孙子听」打卡。
- 三重作用：复习已学字、文化尊严（「我在学唐诗」vs「我在扫盲」的心理差别巨大）、情感闭环。

**③ 小故事阅读课——每学满 100 字解锁一篇，共 5 篇**

- 用已学字撰写 50–80 字生活小故事（赶集、看病、接孙子放学、包饺子、坐公交），大字逐句朗读。
- 老人「第一次独自读完一个故事」的成就感是极强的记忆强化剂。

**里程碑节奏总览**：每 25 字场景课 → 每 50 字古诗课 → 每 75 字场景课 → 每 100 字故事课……每次里程碑只解锁一样新东西，保持惊喜感且不增加选择压力。

### 3.9 「写名字」专项

- 独立入口，输入老人及家人姓名，生成**专属描红字帖**：逐字演示笔顺 + 反复描红，最终能签自己的名字。
- 这是老人最高频的硬需求（领钱、看病、办证都要签名）。

### 3.10 可配置项（设置页）

| 设置项 | 默认值 | 选项 |
|---|---|---|
| 每日新字数 | 5 | 1 / 3 / 5 |
| 书写考核 | 关 | 开 / 关 |
| 字体大小 | 大 | 大 / 特大 |
| 语速 | 慢 | 慢 / 正常 |
| 音量 | — | 系统音量调节入口 |

## 5. 适老化设计规范

### 5.1 视觉

| 项 | 规范 |
|---|---|
| 字号 | 按钮文字 ≥40rpx；正文 ≥36rpx；**被教汉字 ≥200rpx**；页面无任何 <32rpx 文字 |
| 对比度 | ≥4.5:1（WCAG AA）；**禁用蓝紫灰**（老年眼晶状体黄化，蓝紫对比急剧下降） |
| 配色 | 暖色系为主（米黄底 + 深棕/墨绿字），少用纯白刺眼背景 |
| 按钮 | 高度 ≥120rpx，点击热区充分；主按钮唯一且超大 |
| 图片 | AI 插画统一暖色简笔画风，主体突出、无多余细节 |

### 5.2 交互

- **半自动课堂**：教学环节自动播放，仅描红/答题需操作；任何页面 30 秒无操作 → 语音提示下一步。
- **全语音播报**：每个按钮名、每道题的选项、正误反馈、进度全部有语音。
- **零手势**：不设计任何滑动、长按、双击操作，只有「点一下」。
- **防误触**：无弹窗广告、无诱导按钮；关键操作不做二次确认（减少操作步数），退出可随时再进，进度自动保存。
- **容错**：答错永远先说「没关系，我们再看一遍」，永不显示「×」，只用「再试试」+ 语音重读。

### 5.3 文案原则

- 全部口语化、短句、无专业词（「笔顺」说成「怎么写」）。
- 全程不展示拼音：零基础老人同样不识拼音，音频朗读就是他们的「注音」。
- 每次学习结束必表扬，里程碑（50/100/200 字）有额外仪式感播报。

## 6. 内容生产方案

### 6.1 字表与排序

- 字频数据：国家语委字频表 / 《现代汉语语料库字频表》，取前 1500 字，按 500/500/500 分三级。
- 每个字的内容字段（JSON 结构化）：

```
字  拼音(内部用，不展示)  读音音频(TTS)  插画(2:1)  大白话讲解文案  记字诀(字谜/顺口溜)  笔顺数据
组词[2-3个(词+图+音)]  生活例句[1句(大字+音)]  场景课关联
```

### 6.2 音频：TTS 合成

- TTS 提前离线批量生成（500 字 × 字音+讲解+组词+例句 ≈ 3000+ 条），音频托管在自有 CDN。
- 音色要求：亲和的中老年女声/男声，语速调慢一档。
- 改字、纠错可随时重新生成——这是相对真人录音的核心优势。

### 6.3 配图：AI 插画

- 统一风格：暖色简笔画风，1 字 1 图（组词、场景课另有图）。
- 流程：批量生成 → 人工审核（重点：无细节错误、无恐怖谷、主体明确）→ 输出 2:1 尺寸压缩包。
- 抽象虚词（的、是、很）配生活场景插画（客厅、指认动作）。

### 6.4 笔顺动画

- 数据：开源笔顺数据 Make Me a Hanzi（CC 协议），前端渲染动画。
- 描红判定：Canvas 手绘轨迹与标准笔顺的**粗略覆盖度判定**（自研简单算法，宽松实现、不做严格要求），无需第三方手写识别 API。

### 6.5 内容生产流程与工作量

| 环节 | 方式 | 500 字工作量 |
|---|---|---|
| 字表 | 字频数据程序化处理 | 1 人日 |
| 讲解文案 | 撰写（有模板） | 约 10–15 人日 |
| 音频 | TTS 管线批量生成 | 1 人日 + 抽检 |
| 插画 | AI 生成 + 审核 | 约 5 人日 |
| 记字诀 | 大模型批量生成 + 人工审核 | 约 3 人日 |
| 场景课 | 20 节 × 图+文案+音频 | 约 10 人日 |
| 古诗课 | 10 首 × 大字排版+讲解+配图+音频 | 约 3 人日 |
| 故事课 | 5 篇 × 按已学字表撰写+音频 | 约 2 人日 |

## 7. 技术方案概要

| 项 | 方案 |
|---|---|
| 平台 | 微信小程序（无需考虑多端） |
| 后端 | **自有服务器**（REST API，不依赖云开发/云函数） |
| 数据 | 自有数据库按 openid 存：学习进度、已学字、复习队列、错字本、设置项 |
| 课程包 | 自有 CDN 托管 JSON+音频+图片；音频本地缓存减少流量（老人多为流量敏感用户） |
| 复习排期 | 服务端按遗忘曲线（1/2/4/7/15）生成每日复习队列 |
| TTS | 提前离线生成，音频托管在自有 CDN |
| 描红 | Canvas 2D + 粗略覆盖度判定（自研简单实现，宽松判定） |
| 登录 | 微信静默登录（服务端 code 换 openid），免注册、免手机号、无表单 |

成本估算（全免费运营）：TTS 一次性生成成本（自有管线）；持续成本为自有服务器 + CDN 流量。

## 8. 增长与运营

### 8.1 增长飞轮（唯一渠道：子女转发）

```
子女在家庭群/朋友圈看到分享卡片「我爸妈已认识 138 个字」
  → 点开小程序 → 出现「帮爸妈设置」引导（教如何收藏、怎么开始）
  → 爸妈开始学习 → 学习进度进入分享卡片 → 更多子女看到
```

关键动作：
- 分享卡片设计：大字进度 + 场景化文案，转发率是生命线指标。
- 「帮爸妈设置」首次引导页：专为子女设计，30 秒教完收藏路径（小程序 → 右上角 → 添加到我的小程序）。
- 服务通知（V1.1）：每周给子女推送爸妈学习周报，强化持续分享动机。

### 8.2 指标体系

| 层级 | 指标 | 说明 |
|---|---|---|
| 北极星 | 周学习 ≥3 天活跃学员数 | 学习粘性 = 教学效果代理 |
| 增长 | 转发率 = 分享次数 / 打开次数 | 唯一渠道健康度 |
| 效果 | 入门级 500 字完成率 | 季度目标 |
| 体验 | 单次学习时长中位数 | 观察复习负荷（预警 >20 分钟） |
| 留存 | 次月留存率 | 老年产品参考线 ~30% |
